# Life Spiral

A [renCal](https://rencal.org) view: years of your life as one psychedelic sausage coiling around itself, a day per segment.

## Install

Install it from renCal's plugin directory, or add it to the `plugins` array in renCal's `plugins.toml`:

```toml
plugins = ["larskarbo/rencal-view-life-spiral"]
```

## Develop

```sh
npm install
npm run dev
```

Add the checkout's path to `plugins.toml` to load it live.
